# 赛车游戏原型

这是一个独立的新项目，目标是制作一款小规模、可玩的 3D 赛车游戏原型。

## 目标方向

- 参考开放世界赛车的自由驾驶感
- 参考竞速游戏的赛道、计时和分段成绩
- 第一阶段只做一辆车、一张赛道、一个比赛模式
- 优先实现稳定的驾驶手感，再逐步增加车辆、赛道和环境

## 第一版建议

1. 车辆加速、刹车、转向和倒车
2. 第三人称跟车镜头
3. 起点、终点和检查点
4. 圈数、计时和排名
5. 简单碰撞与重置车辆
6. 赛后成绩界面

## 参考竞速产品的交互层

本原型借鉴了现代赛车游戏常见的广播包装：进入比赛前按“模式 → 赛道 → 比赛设置 → 准备发车”分步确认，比赛中提供转速条、档位、计时、最佳圈、赛道缩略图，以及视角 / 暂停 / 菜单入口。视觉采用深色网格、白色分隔线和橙红色强调色，品牌与文案均为 Apex Ridge 自有内容。

## 规模控制

本项目不直接复刻《极限竞速：地平线》或《神力科莎》的完整规模。先做一个单赛道原型，确认驾驶手感和竞速循环，再决定是否扩展到开放区域、AI 对手、车辆改装和联网功能。

## 当前原型

- `src/main.js`：Three.js 场景、赛车控制、赛道、计时和镜头
- 赛道节奏：150m 主直道、高速弯、长回程直道、发夹弯和连续 S 弯
- 赛道环境：Kenney 看台、维修区、灯杆、广告牌，程序化红白路肩、刹车牌、轮胎墙、山体与云层
- 引擎声：使用 Web Audio API 根据车速和油门实时合成，并按 N / 1–6 档切换振荡器音色、谐波比例和滤波频段；叠加风噪、轮胎摩擦噪声和换挡提示音，不依赖额外音频文件
- `src/style.css`：赛事大厅、赛道卡片、设置页、暂停层和比赛 HUD
- `public/assets/racing-kit/`：Kenney Racing Kit（车辆、赛道设施和障碍物）
- `地图设计方案.md`：五张地图的玩家承诺、赛道节奏、决策点、地标、风险 / 恢复段和资产复用方案
- `资源清单.md`：已下载资源包、本地目录和实际接入点

资源来源：[Kenney Racing Kit](https://kenney.nl/assets/racing-kit)，页面标注 Creative Commons CC0。

## 运行

```bash
npm install --cache .npm-cache
npm run dev
```

浏览器打开终端提示的本地地址，依次选择模式、赛道和圈数后点击“开始比赛”。比赛中可用 `C` 或右上角按钮切换三种镜头，`ESC` 暂停，`R` 重置车辆。
